# Stalcraft Auction Search UI

Простая статическая страница для поиска предметов и просмотра актуальных цен на аукционе Stalcraft через публичное API `https://eapi.stalcraft.net/`.

## Возможности
- Поиск по названию предмета с учётом выбранного региона (RU, EU, SEA).
- Поддержка Bearer-токена, если эндпоинт требует авторизации.
- Расчёт минимальной, средней и максимальной цены по найденным лотам.
- Отображение базовой информации о продавце, количестве и сроке действия лота.

## Как использовать
1. Откройте `index.html` в браузере (подойдёт локальный `Live Server` или любой статический хостинг).
2. Введите название предмета, выберите регион и, при необходимости, вставьте Bearer-токен в поле «Токен авторизации».
3. Нажмите «Найти цены» и дождитесь загрузки результатов.

> Примечание: конечные URL и структура ответа зависят от актуальной версии API Stalcraft. Если какие-то поля отличаются, приложение всё равно попытается подобрать ключи цены и количества автоматически.
